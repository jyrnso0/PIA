# Glosario de dominio — AulaPlus

Transcripción del [glosario entregado para el Caso 08](./source/Glossary_AulaPlus.pdf).

| Término | Definición |
|---|---|
| Tutoría | Servicio de enseñanza que un tutor imparte a un estudiante, presencial o en línea. |
| Modalidad | Forma en que se realiza la tutoría: presencial o en línea. |
| Reserva | Solicitud que hace el estudiante para apartar un horario de tutoría con un tutor. |
| Disponibilidad | Días, horarios, materias y modalidad que un tutor tiene registrados para dar clases. |
| Asignación de tutor | Proceso con el que la plataforma determina qué tutor atiende una reserva, según su disponibilidad. |
| Sesión | Encuentro de tutoría entre estudiante y tutor, ya confirmado y con horario definido. |
| Checklist de confirmación | Registro donde estudiante y tutor marcan que la sesión sí se llevó a cabo. |
| Evidencia de sesión | Checklist y marcas de tiempo que respaldan que la sesión ocurrió y en qué condiciones. |
| Ausencia | Situación en la que el estudiante o el tutor no se presenta a una sesión programada. |
| Cancelación | Acción de dejar sin efecto una sesión programada por parte del estudiante o del tutor. |
| Penalización | Cargo aplicado a quien cancela fuera del tiempo mínimo permitido. |
| Disputa | Desacuerdo sobre si la sesión se realizó o en qué condiciones, que se turna a Soporte. |
| Soporte | Área encargada de atender incidencias y resolver disputas dentro de la plataforma. |
| Incidencia | Situación que interrumpe o afecta el desarrollo normal de una sesión. |
| Reembolso | Devolución del dinero pagado por una sesión, cuando lo determinan las reglas del negocio. |
| Pago | Transacción que hace el estudiante para cubrir el costo de una sesión. |
| Comisión | Porcentaje que retiene AulaPlus sobre cada sesión pagada. |
| Suspensión | Bloqueo temporal de la cuenta de un tutor cuando acumula demasiadas ausencias. |
| Calificación | Evaluación que estudiante y tutor se dan mutuamente después de la sesión. |
| Dashboard | Panel donde Administración revisa comisión, cancelaciones, disputas y calificaciones. |
| Materia | Área de conocimiento sobre la que un estudiante pide ayuda. |
| Tema | Contenido puntual que el estudiante quiere trabajar dentro de una materia. |
| Fecha | Día en que se llevará a cabo la sesión. |
| Horario | Rango de tiempo asignado para la sesión. |
| Estudiante | Persona que solicita y recibe una tutoría. |
| Tutor | Persona que ofrece e imparte tutorías particulares. |
| AulaPlus | Plataforma que conecta estudiantes con tutores particulares y cobra una comisión por cada sesión realizada. |
